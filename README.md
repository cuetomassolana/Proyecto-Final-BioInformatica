# Proyecto-Final-BioInformatica
Reanálisis de transcriptómica (GEO GSE110830 y GSE80178) para identificar los genes que activa la estimulación eléctrica en células de la piel, su relación con la úlcera de pie diabético y un candidato a biomarcador (EREG). Proyecto final de Bioinformática, UNSTA 2026. Solana Cueto Mas
